# Amazon Clone (HTML & CSS)

## Overview
This project is a front-end clone of the Amazon homepage created using HTML5 and CSS3. It is designed to replicate the look and feel of Amazon's interface while improving front-end development skills.

## Features
- Responsive layout
- Amazon-inspired user interface
- Navigation bar
- Search bar
- Hero section
- Product cards
- Footer section
- Clean and well-structured code
- Pure HTML and CSS (No JavaScript)

## Technologies Used
- HTML5
- CSS3

## Project Structure
amazon-clone/
│── index.html
│── style.css
│── images/
└── assets/

## Purpose
This project was developed for learning and practicing front-end web development concepts, including semantic HTML, CSS layouts, Flexbox, Grid, and responsive design.
